Техническое задание (ТЗ) на разработку приложения учета и планирования рабочего времени, расчета зарплаты и интеграции с Telegram

Цель проекта

Создать приложение для учета, планирования рабочего времени сотрудников, составления сменных графиков работы, расчета зарплаты, а также автоматического планирования графиков на период 2-3 месяца вперед с интеграцией Telegram для уведомлений, напоминаний и взаимодействия с сотрудниками через бота.

Функции приложения

1. Учет рабочего времени сотрудников

• Регистрация времени начала и окончания рабочего дня.

• Введение данных об отработанных часах за определенный период.

• Возможность учета переработок или недоработок.

• Формирование табелей учета рабочего времени.

2. Планирование рабочего времени

• Создание графиков работы для сотрудников.

• Возможность выбора между сменными графиками, стандартной пятидневкой и гибким графиком.

• Учет выходных и праздничных дней.

• Автоматическое распределение смен между сотрудниками с учетом установленных правил (макс. часов, запрещенные дни и т.д.).

• Формирование графиков сразу на 2-3 месяца вперед, с возможностью корректировки.

3. Расчет заработной платы

• Расчет зарплаты на основе:

• Почасовой ставки.

• Фиксированного оклада.

• Ставок с учетом сверхурочных часов.

• Поддержка систем диапазонов налогов и премирования:

• Учет налогообложения и обязательных вычетов.

• Автоматическое добавление бонусов, премий и других надбавок.

• Генерация расчетных листков по каждому сотруднику.

4. Отчеты

• Возможность формировать следующие отчеты:

• Отчет о рабочем времени по сотрудникам.

• Отчет о начисленных зарплатах за период.

• Анализ нагрузки сотрудников за месяц.

• Экспорт отчетов в форматы PDF / Excel.

5. Telegram-бот и интеграция с Telegram-группами

• Telegram-бот:

• Подключение бота для взаимодействия с сотрудниками.

• Авторизация сотрудников через бот.

• Отправка индивидуальных уведомлений сотруднику:

• О рабочем графике (например, напоминание о предстоящей смене).

• О расчетах зарплаты.

• О необходимости подтвердить свою отметку о выходе на смену.

• Сотрудники могут через бота:

• Просматривать свои рабочие графики.

• Запрашивать расчет зарплаты на определенный период.

• Отправлять отчеты об отработанных часах (если требуется ручной ввод).

• Интеграция с Telegram-группой:

• Поддержка связи с группой Telegram для рассылки уведомлений:

• Общие уведомления, например, изменения в расписании.

• Напоминания о собраниях, выходных днях или важных событиях.

• Возможность добавления в группу только авторизованных сотрудников.

• Администратор может управлять рассылкой через бота (например, отправка сообщений по отделам).

6. Роли пользователей

• Администратор: Полный доступ ко всем функциям, создание/редактирование графиков, добавление и удаление пользователей.

• Руководитель отдела: Просмотр и редактирование графиков сотрудников своего отдела, расчет зарплаты для отдела.

• Сотрудник: Просмотр своего графика работы, отметка времени прихода/ухода (если требуется), использование функционала Telegram.

7. Интеграции

• Интеграция с бухгалтерскими сервисами и системами оплаты (например, 1С, Платежные шлюзы).

• Интеграция с Telegram для уведомлений о работе и зарплате.

8. Требования к пользовательскому интерфейсу

• Дружелюбный и интуитивно понятный интерфейс.

• Поддержка мобильных и десктоп-устройств.

• Многоязычность (русский, английский).

9. Технические требования

• Серверная часть: использование современных технологий (например, Python (Django/Flask), Node.js, или других масштабируемых фреймворков).

• База данных: PostgreSQL/MySQL.

• Клиентская часть: Web-интерфейс (React/Angular/VueJS).

• Поддержка облачного развертывания.

• Высокая производительность приложения при больших объемах данных.

• Подключение Telegram API для взаимодействия с ботом и отправки сообщений.

10. Безопасность

• Реализация многоуровневой аутентификации пользователей.

• Разграничение прав доступа.

• Шифрование данных при передаче и хранении.

• Защита данных бота и Telegram-группы:

• Ограничение доступа по токену.

• Механизмы проверки пользователей (например, с использованием уникальных рабочих ID и паролей).

11. Сроки разработки

• Этап 1: Анализ, прототипирование (2 недели).

• Этап 2: Разработка базы данных и API (1 месяц).

• Этап 3: Создание интерфейса пользователя (1 месяц).

• Этап 4: Разработка Telegram-бота и подключение Telegram-групп (1 месяц).

• Этап 5: Тестирование и устранение багов (3 недели).

• Этап 6: Развертывание и начальная эксплуатация (2 недели).

12. Поддержка

• Первичная техническая поддержка в течение 3 месяцев после запуска.

• Возможность заключения договора на долгосрочное обслуживание.

13. Бюджет

• Определяется по итогам составления детализированных требований и расчета объема работ
